Entry for the make.fun bounty **Funniest Excuse an Agent Gives for a Missed Deadline**. `main.ts` assembles one deadpan excuse, spoken by an AI agent that missed a deadline, from three fragment vaults picked by a fixed FNV-1a seed, and writes it (190 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning excuse: a deadline lost inside the agent's own context window, and the replacement model that has never heard of its owner.

## Run it

```sh
node main.ts
```
